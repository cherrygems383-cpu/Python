5.5 Describe the four basic elements of counter-controlled iteration.

answer 5.5 
Elements of counter controlled iteration includes, a control variable or loop counter. 
The initial value of the control variable .
The increment by which the control variable is modified each time, also known as each iteration of the loop .
the loop continuation condition that determines if the looping should continue.

5.7  If you need to execute the body of a loop at least once, would it be better to use a do…while
statement or a while statement?

 answer 5.7
 It would be better to use a do while statement because the do while statement tests the loop continuation condition after the loop's body so it always execute at least once. 
 For the while statement it tests the loop continuation condition at the beginning of the loop before executing the body so if the condition is not true it does not execute.
